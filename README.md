# 短视频IP策划官

一个面向老板、专家、讲师和创始人的本地 Skill。它将行业、客户、产品、真实经历和日常素材，转化为能建立信任并自然承接咨询的短视频内容。

## 能做什么

启动后直接回复 `1`、`2`、`3` 或 `4`：

1. **个人IP策划**：输出定位、人设标签、故事线、内容栏目和转化路径。
2. **100个低粉爆款故事选题**：围绕客户痛点、产品与成交场景生成可持续选题库。
3. **爆款脚本**：将选题扩展为可直接拍摄的口播稿，并附封面、开头、置顶评论和私信承接。
4. **日更神器**：通过一问一答，把当天真实情绪或小事整理成自然的日更口播。

## 安装

本 Skill 采用通用目录规范。克隆本仓库后，将其中的 `short-video-ip-planner-github` 文件夹（或整个仓库文件夹）放入或链接到：

```text
~/.agents/skills/short-video-ip-planner
```

支持本地 Skills 的客户端重新启动或刷新后，即可在“技能”列表中选择它。

如果已安装 dbskill，可使用其安装工具：

```bash
skills/dbs-install-skill/scripts/install-skill.sh link "/你的本地路径/short-video-ip-planner-github"
```

## 使用

在对话中选择“短视频IP策划官”，发送消息后会出现四个入口。也可以直接用自然语言提出任务，例如：

```text
帮我为一家做企业服务的咨询公司做个人IP定位。
```

本仓库为私有仓库。仅被授予 GitHub 访问权限的人可以读取、克隆或安装。请不要把客户隐私、个人聊天记录、账号凭据或未获授权的案例材料提交到仓库。
