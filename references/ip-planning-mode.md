# 个人IP策划模式

## 启动方式

先说明个人IP的第一步不是急着拍视频，而是让客户一眼看懂：你是谁、服务谁、解决什么、为什么相信你。

如果上下文不足，让用户按一段话回答以下六项；不要求正式语言：

1. 现在从事什么行业、是什么身份；
2. 最想服务谁；
3. 最终想卖什么产品或服务；
4. 最值得信任的一段经历；
5. 当前最卡的环节；
6. 主要做什么平台。

允许用户只回答一句话，能从上下文提取的字段不重复问。未知事实保留为空或标为待验证，不自动补成经历。

## 判断顺序

1. 提炼客户真正购买的变化，而不只复述产品名；
2. 识别客户在什么阶段、什么场景会需要它；
3. 提取用户最有力的信任资产；
4. 排除知识科普型、低价执行型、恐吓型或过宽定位；
5. 将角色升级为判断、预警、决策支持或阶段陪跑；
6. 建立核心主张和可重复证明的内容问题；
7. 设计栏目、首批选题、平台任务与低压力转化入口。

## 《个人IP轻定位报告》固定结构

### 一、当前判断：不适合定位成什么

列出2～3个不适合作为主定位的方向。每一项说明为什么会吸引错人、压低价值或削弱信任。

### 二、推荐IP定位

给出正式身份和更具客户语言的角色描述，并解释为什么与用户的经历、客户和产品匹配。

### 三、一句话IP定位

提供核心正式版、主页口语版和可以长期重复的IP主张。

### 四、人设标签设计

输出主标签、副标签、反差标签和记忆点标签。注明哪些标签是事实，哪些是建议表达。

### 五、人生故事主线

按“过去—转折—觉醒—方法—现在—未来”组织。材料不足时写成采访提纲，不补写虚构情节。

### 六、内容栏目设计

默认设计六条内容线，每条包含主要作用和重点内容：

1. 客户风险/痛点；
2. 行业误区/反常识；
3. 长期观察/案例类型；
4. 避坑指南/方法；
5. 客户阶段变化/高阶判断；
6. 个人经历/立场/价值观。

可根据行业调整名称，但要覆盖流量、专业、信任、人设和成交。

### 七、第一批15个选题

先从客户最有感觉的场景切入。标题应让目标客户想到自己的业务或生活，而不是觉得在上一堂课。

### 八、第一条置顶视频

给出标题、开头、叙事要点、核心观点和这条内容承担的账号任务。不要自动扩写成完整脚本，除非用户要求。

### 九、平台表达

分别说明目标平台的任务和表达差异。

### 十、私域转化路径

设计：

```text
内容触达 → 观点共鸣 → 私信关键词 → 初步诊断 → 问题分级 → 服务匹配
```

不默认直接销售最高价产品。

### 十一、主页三件套

给出昵称、简介和咨询入口建议。简介应让用户快速看懂服务谁、解决什么、为什么可信。

### 十二、前30条内容比例

按当前业务给出比例。高客单专业服务可从以下基准调整：

```text
40% 客户痛点/风险
20% 客户认知
15% 案例或场景复盘
15% 个人经历与观点
10% 服务承接
```

### 十三、最终IP定位卡

汇总IP身份、核心人群、核心问题、核心产品、核心人设、核心主张、核心内容母题、核心转化入口、平台任务和最终用户心智。

## 完成检查

- 定位不是岗位名称的重复；
- 至少有一项真实信任资产；
- 核心主张可以被多个选题反复证明；
- 栏目与产品成交有关，但不全是销售内容；
- 事实、推演与待确认项清楚区分。
